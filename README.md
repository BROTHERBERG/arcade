# Cabinet Arcade - Orthodontie

Website for Cabinet d'Orthodontie Arcade in Saint-Denis, La Réunion.

## Tech Stack

- **React 18** - Modern UI framework
- **TypeScript** - Type safety
- **Vite** - Lightning-fast dev server
- **Tailwind CSS** - Utility-first styling
- **Lucide React** - Beautiful icon library

## Development

```bash
# Install dependencies
npm install

# Start dev server (http://localhost:5173)
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- Responsive design (mobile-first)
- Smooth scroll animations with Intersection Observer
- Custom Reveal animations
- Floating Action Buttons (FAB) for quick contact
- Interactive FAQ accordion
- Google Maps integration
- Modal for appointment booking
- Montserrat font throughout

## Sections

1. **Hero** - Main landing with prominent imagery
2. **Team** - Dr. Matthieu Hutin & staff profiles
3. **Cabinet** - Office tour and Dentapoche app promotion
4. **Appareils** - Orthodontic devices showcase
5. **Parcours** - Treatment journey timeline
6. **Traitements** - Treatment types (functional, orthopedic, adult, surgery)
7. **Technologies** - 3D imaging and modern equipment
8. **FAQ** - Common questions
9. **Map** - Location and access info
10. **Footer** - Contact details and hours
